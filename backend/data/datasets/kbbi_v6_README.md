## English

### Description
The KBBI v6.1.0 Full Database is an extensive extraction of the official Kamus Besar Bahasa Indonesia. This repository provides a high-performance, spreadsheet-ready CSV file containing over 194,000 entries.

### Primary Asset
- **[kbbi_v6.1.0_full.csv](kbbi_v6.1.0_full.csv)**: Master dataset featuring lemas, pronunciations, etymologies, multiple meanings, examples, and linguistic tags.

### Key Features
- **Spreadsheet Integration**: All internal newlines have been stripped for compatibility with Excel, Google Sheets, and Pandas.
- **Rich Metadata**: Includes tags for Word Class, Language Origin, Field of Study, and Usage Register.
